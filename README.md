# 谈吐 · 网页版（v0.2.1）

与小程序同一套语料、同一套评分口径、同一套六维模型，改成了浏览器里直接打开的单页应用。没有后端、不打包、不依赖框架，三个文件加一份语料数据。

## 打开

三种方式，任选：

1. **直接双击 `index.html`**（Chrome / Edge 可用，麦克风需要授权）。
2. **起一个本地服务**（推荐，麦克风权限最稳）：双击 `serve.py`，或命令行
   ```
   python3 serve.py
   ```
   会自动打开 `http://localhost:8000`。
3. **丢到任意静态托管**（对象存储、Vercel、GitHub Pages），把整个目录上传即可。

浏览器要求：Chrome 90+ / Edge 90+ / Safari 15+。录音依赖 `getUserMedia`，`file://` 在 Chrome 里可用，Safari 下建议走 `localhost`。

## 放到手机上

v0.2.1 起是手机优先的布局：底部五个标签、单列卡片、输入框 16px 防缩放、状态栏与刘海自适应，并带 `manifest.json` + `sw.js`，可"添加到主屏幕"当 App 用（PWA）。

两条路，按需选：

**A. 同一 Wi-Fi 局域网（最快，手机能录音）**

1. 电脑上运行 `python3 serve.py --https`，会打印手机可访问的 `https://192.168.x.x:8443`。
2. 手机连同一 Wi-Fi，浏览器打开这个地址。
3. 首次提示"证书不受信任"→ 选"高级/继续访问"（自签证书，只影响这一次）。
4. 要装到桌面：Safari 点分享 →"添加到主屏幕"；Chrome/Edge 点右上角菜单 →"添加到主屏幕"。

必须用 `--https`：浏览器规定 `getUserMedia` 只在安全上下文（https 或 localhost）可用。直接 `serve.py`（http://…:8000）手机能看能点，但**录音按钮会拿不到麦克风**。

**B. 公网静态托管（一次部署，随时可用）**

把整个 `网页版` 目录拖进 Netlify / Vercel / 对象存储静态站点，拿到 `https://` 域名即可（HTTPS 由平台提供，录音自然可用）。手机打开后同样可以"添加到主屏幕"。

注意：`index.html`、`assets/`、`manifest.json`、`sw.js` 必须放在同一层，`sw.js` 要在根路径才能接管整个站点。

**iOS 小贴士**：首次点录音时系统会弹权限；若之前拒过，去 设置 → Safari → 麦克风 里改。PWA 模式下录音同样可用，但来电或切后台会中断，页面会提示重新开始。

## 功能

| 视图 | 做什么 |
|---|---|
| 今日 | 三件事（读一段／拆一段／说一段）、六维档案、连续天数 |
| 语料库 | 69 条精选，按七库筛选、关键词搜索、详情弹窗（为什么好／怎么用／误用边界） |
| 训练 | 跟读、实战、文字三种模式；录音、计时、电平、停顿与音量分析 |
| 报告 | 总分、六维雷达、实测指标、三条改动、示范开场、下一条推荐 |
| 我的 | 连续天数／开口次数／累计分钟、趋势柱、语料使用谱、收藏、清空 |

**文字模式是网页版特有的**：没有麦克风或不想出声时，把要说的话敲进去，按真实文本统计给「有物／有序／有采」三档评分，并指到具体句子；「有情／有度／有节」标未评。

## 评分口径

- **有节**：录音逐帧（32ms）算 RMS，取 10% 分位做噪声底，阈值 `max(底×2.2, 0.006)`，连续 12 帧（约 0.38 秒）静音记一次有效停顿；音量波动系数由发声帧的标准差／均值得到。
- **语速**：仅跟读模式按「汉字数／时长」计算，健康区间 130–240 字/分；原文不足 20 字不测，避免误判。
- **有物 / 有序 / 有采 / 有度 / 有情**：结论句、举例、数字、引用、连接词密度、平均句长、句长方差、口头禅占比 + 勾选项。权重 30/25/10/10/15/10，只对已评项归一。
- 录音、文字稿都只留在浏览器内存与 `localStorage`，不上传。

## 与小程序的关系

- 共用：`data.js`（由小程序 `data/corpus.js` 直接导出）、评分算法、六维权重、点评三段式。
- 不同：网页版多了文字评测与桌面双栏布局；小程序多了原生 tabBar、真机录音与微信分享。
- 数据不互通：小程序存在 `tantou_state_v1`（wx storage），网页存在 `tantou_web_v1`（localStorage）。

## 接后端

`assets/app.js` 里三处替换即可：

1. `computeReport()` → 改为 `POST /v1/drill/attempt`，返回同样的 `dims / scored / total / metrics / text`。
2. `advice()` → 改为模型返回的 `advice[]`，字段保持 `{tag, quote, why, fix}`。
3. `rec` 的录音 → 可选上传原始音频换 ASR 转写，`transcript` 由服务端回填。

接口契约与小程序版 README 一致，两端可以共用一个后端。

## 已知限制

- 无账号、无云同步；换浏览器或清缓存即丢档案。
- 无 TTS 示范音，跟读靠文字与朗读提示。
- 语料是 69 条演示子集，商用前需按《经典语料库建设清单》补齐权利状态与证据。
- 移动端已适配（底部标签栏、PWA 安装、iOS 音频解锁），但仍是单机存储，无账号同步。
